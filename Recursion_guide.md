Step by step guide to how to write a recursive function.
1. Understand what you are trying to return or output. 
2. Find the base case. The case where the recursion stops. 
3. Find a recursion step: a step that recursively gets closer to the base case.

Fundamental rules:
1. You have to have a certain return type.
2. You need to have a parameter in order to recursively update the condition.
